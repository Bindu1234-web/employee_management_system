# Employee Management System

A web-based Employee Management System developed using Java and Spring Boot. The project provides employee CRUD operations through REST APIs and includes a simple web interface.

## Features

- Add employee details
- View employee details
- Update employee details
- Delete employee details
- Employee CRUD operations
- REST API integration
- Web-based user interface
- Database integration

## Technologies Used

- Java 17
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- Maven
- H2 Database
- MySQL Connector
- Lombok
- HTML
- CSS
- JavaScript
- Postman
- IntelliJ IDEA

## API Testing

The REST APIs were tested using Postman for CRUD operations and response validation.

### API Operations

- POST - Add employee
- GET - View employee details
- PUT - Update employee details
- DELETE - Delete employee
