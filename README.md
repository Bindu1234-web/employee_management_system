# Employee Management System

A web-based Employee Management System developed using Java, Spring Boot, REST APIs, and PostgreSQL.

## Features

- Add employee details
- View employee details
- Update employee details
- Delete employee details
- Employee CRUD operations
- REST API integration
- Database connectivity using PostgreSQL

## Technologies Used

- Java
- Spring Boot
- REST APIs
- PostgreSQL
- Maven
- Postman
- HTML
- CSS
- JavaScript

## API Testing

The REST APIs were tested using Postman for CRUD operations and API response validation.

- Landing Page

- Backend running in IntelliJ

## Project Structure

The backend is developed using Spring Boot and Maven.

PostgreSQL is used to store employee information.
